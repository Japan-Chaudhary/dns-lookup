# DNS & IP Lookup Tool

A Python-based CLI tool for performing domain and DNS lookups using Python socket programming and the `dnspython` library.

This project helps explore how domain resolution, DNS records, reverse DNS lookups, and IP address information work behind the scenes.

---

## Features

- Basic IPv4 lookup
- Extended hostname and alias lookup
- IPv4 & IPv6 address resolution
- Reverse DNS lookup
- PTR record lookup
- DNS record querying using `dnspython`
- Full domain information report
- Interactive CLI menu system
- Command-line argument support

---

## Supported DNS Records

- A
- AAAA
- MX
- NS
- CNAME
- TXT
- SOA
- PTR

---

## Technologies Used

- Python 3
- Socket Programming
- dnspython
